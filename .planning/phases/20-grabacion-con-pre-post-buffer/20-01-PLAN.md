<interfaces>
```python
@dataclass(slots=True)
class BufferedFrame:
    seq: int
    wall_clock: datetime
    jpeg: bytes


class RingFrameBuffer:
    def __init__(self, seconds: float, fps: float, max_bytes: int) -> None: ...
    def push(self, frame: Frame) -> None:
        """Encodea a JPEG y anade al buffer, descartando el mas antiguo si procede."""
    def drain(self) -> list[BufferedFrame]:
        """Devuelve el contenido actual en orden cronologico sin vaciarlo."""
    def clear(self) -> None: ...
    @property
    def bytes_used(self) -> int: ...
    @property
    def span_seconds(self) -> float: ...   # antiguedad del frame mas viejo
```

Implementacion: `collections.deque` sin `maxlen` (la purga se hace por dos criterios simultaneos: numero de frames y bytes) mas un `threading.Lock` y un contador de bytes incremental.

```python
def push(self, frame: Frame) -> None:
    ok, buf = cv2.imencode(".jpg", frame.image,
                           [int(cv2.IMWRITE_JPEG_QUALITY), self._quality])
    if not ok:
        return
    item = BufferedFrame(frame.seq, frame.wall_clock, buf.tobytes())
    with self._lock:
        self._items.append(item)
        self._bytes += len(item.jpeg)
        while self._items and (
            len(self._items) > self._max_frames or self._bytes > self._max_bytes
        ):
            old = self._items.popleft()
            self._bytes -= len(old.jpeg)
```

Reescribir `backend/pipeline/recording.py`.

Estructura:

```
[Subscription broker] → _feed_loop (hilo)  → RingFrameBuffer
                                           → _live_queue (si hay clip activo)

[peticiones de clip]  → _assembly_loop (hilo) → drena prebuffer
                                              → escribe MP4
                                              → consume _live_queue hasta post_buffer
                                              → registra metadatos (plan 20-02)
```

Puntos criticos:

1. **Un solo clip activo a la vez.** Si llega un segundo evento `record` mientras hay un clip en curso, se extiende la ventana de post-buffer en lugar de abrir otro clip. Sin esto, una intrusion prolongada genera decenas de clips solapados.

2. **`_live_queue` acotada.** Si el ensamblado se retrasa, se descartan frames en vivo antes que crecer sin limite. Contabilizarlo.

3. **El pre-buffer no se vacia al usarlo.** `drain()` devuelve una copia; el buffer sigue llenandose para el siguiente evento.

4. `ClipRecorder` (`backend/recorder.py`) se retira o se reduce a la escritura del MP4 (`VideoWriter` + `imdecode`), sin logica de decision de cuando grabar.
