Parametros comunes a los cuatro endpoints:

```
camera_id : str        Query(default="cam1")
from      : date       Query(alias="from")   # inclusivo, YYYY-MM-DD
to        : date       Query(alias="to")     # INCLUSIVO: se traduce a to+1 dia exclusivo
```

`from` y `to` son palabras reservadas o casi en Python: se declaran como `from_` / `to_`
con `Query(alias="from")` y `Query(alias="to")`. Tipo `datetime.date`, **no** `str`: asi el
422 de una fecha basura lo da Pydantic y no una `if` del cuerpo (V5 del Security Domain).

Validacion del rango, en un helper compartido `_resolve_range(from_, to_)`:

| Caso | Respuesta |
|---|---|
| `to_ < from_` | `HTTPException(422, "La fecha «Hasta» debe ser posterior a «Desde».")` |
| `(to_ - from_).days + 1 > 90` | `HTTPException(422, "El rango máximo es de 90 días.")` |
| resto | `(cur_from, cur_to, span_days)` con `cur_from = datetime(from_, 00:00:00)`, `cur_to = datetime(to_+1dia, 00:00:00)` |

Las dos cadenas son **literales de la tabla de copy del UI-SPEC**; el cliente las repite en
su validacion de cortesia, asi que tienen que coincidir palabra por palabra.

**Por que `peak_index`/`min_index`/`chart`/`has_previous`/`truncated` y no que los calcule el cliente:**
`Math.max()` esta prohibido por D-07 y auditado con `grep` en 31-11. Un indice es acceso
directo por posicion; un maximo es agregacion. La diferencia no es de estilo.

Formato de etiquetas (funcion `_label(dt, bucket, span_days)`), meses en castellano
abreviados con la constante `_MESES = ("ene","feb","mar","abr","may","jun","jul","ago","sep","oct","nov","dic")`:

| bucket | span | etiqueta |
|---|---|---|
| `hour` | 1 dia | `"14:00"` |
| `hour` | > 1 dia | `"16 ago 14:00"` |
| `day` | cualquiera | `"16 ago"` |

La misma funcion produce `peak.label` y `min.label` de `/summary`, para que la anotacion
"Pico {HH:00} · {N}" de la cabecera del panel y la etiqueta del eje digan lo mismo.

    **2) Helpers de modulo:**

    ```python
    MAX_RANGE_DAYS = 90
    _MESES = ("ene", "feb", "mar", "abr", "may", "jun", "jul", "ago", "sep", "oct", "nov", "dic")


    def _resolve_range(from_: datetime.date, to_: datetime.date) -> tuple[datetime.datetime, datetime.datetime, int]:
        """Rango inclusivo del cliente -> ventana semiabierta [cur_from, cur_to).

        Las dos cadenas de error son literales de la tabla de copy del UI-SPEC: el
        cliente valida lo mismo antes de pedir nada, pero la autoridad es esta.
        """
        if to_ < from_:
            raise HTTPException(status_code=422, detail="La fecha «Hasta» debe ser posterior a «Desde».")
        span_days = (to_ - from_).days + 1
        if span_days > MAX_RANGE_DAYS:
            raise HTTPException(status_code=422, detail="El rango máximo es de 90 días.")
        cur_from = datetime.datetime.combine(from_, datetime.time.min)
        cur_to = datetime.datetime.combine(to_ + datetime.timedelta(days=1), datetime.time.min)
        return cur_from, cur_to, span_days


    def _label(dt: datetime.datetime, bucket: str, span_days: int) -> str:
        if bucket == "day":
            return f"{dt.day} {_MESES[dt.month - 1]}"
        if span_days <= 1:
            return f"{dt.hour:02d}:00"
        return f"{dt.day} {_MESES[dt.month - 1]} {dt.hour:02d}:00"


    def _axis(start, end, bucket) -> list[datetime.datetime]:
        """Eje completo de cubos [start, end), paso de 1 hora o de 1 dia."""
        step = datetime.timedelta(hours=1) if bucket == "hour" else datetime.timedelta(days=1)
        out, cur = [], start
        while cur < end:
            out.append(cur)
            cur += step
        return out


    def _key(dt: datetime.datetime, bucket: str) -> str:
        """Misma forma que devuelve substr(ts,1,13|10) en AnalyticsRepo."""
        return dt.strftime("%Y-%m-%d %H") if bucket == "hour" else dt.strftime("%Y-%m-%d")
    ```
