    **1) `markPerson.js` — confirmación:**
    ```javascript
    async function onConfirm() {
      const name = document.getElementById('mark-person-name').value.trim();
      if (!name) { showError('Escribe un nombre.'); return; }
      setBusy(true);
      try {
        const fd = new FormData();
        fd.append('name', name);
        if (_ctx.snapshotUrl) {
          const res = await fetch(_ctx.snapshotUrl);
          if (!res.ok) throw new Error('snapshot');
          const blob = await res.blob();
          fd.append('image', blob, 'snapshot.jpg');   // reutiliza las validaciones de /api/enroll_face
        } else {
          fd.append('use_current_frame', 'true');
        }
        const enrolled = await apiFetch('/api/enroll_face', { method: 'POST', body: fd });
        const applied = await apiFetch(
          `/api/v2/events/${encodeURIComponent(_ctx.eventId)}/assign-person`,
          { method: 'POST', headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ person_id: enrolled.person_id }) });
        applyPersonAssignment(applied.event_ids, enrolled.person_id, enrolled.name);
        showToast(`Identidad aplicada a ${applied.updated} eventos de este track.`, 'success');
        close();
      } catch (err) {
        showError('No se pudo guardar la identidad. Inténtalo de nuevo.');
      } finally {
        setBusy(false);
      }
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Navegador → `POST /api/enroll_face` | Se sube una imagen (el recorte del evento) y un nombre escrito por el operador |
| Navegador → `POST /api/v2/events/{id}/assign-person` | Se muta la identidad de un conjunto de filas |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-30-37 | Elevation of Privilege | Enrolado saltándose las validaciones de imagen | mitigate | Se llama al `/api/enroll_face` existente, que ya valida `content_type`, ≤10 MB y `max_length=100`, con rate limit propio (5/minute) y tests de regresión. No se crea ningún camino alternativo de enrolado |
| T-30-38 | Tampering | Identidad aplicada a eventos de otra persona | mitigate | El alcance lo calcula el servidor (`track_scope`, 30-03) con la triple cota; el cliente solo muestra el número y envía el `event_id` ancla |
| T-30-39 | Tampering (XSS) | Nombre de persona recién enrolado repintado en las filas | mitigate | `applyPersonAssignment` solo actualiza el modelo y llama a `render()`, que usa `textContent`; el `datalist` asigna `option.value` por propiedad |
| T-30-40 | Denial of Service | Doble clic creando dos personas con el mismo nombre | mitigate | `setBusy(true)` deshabilita el botón durante la operación y lo restaura en `finally` |
</threat_model>
